# 报价文件格式目录（真实样本归纳 v1）

来源：万达工业集团历史报价库 232 个文件 / 45+ 品类（机电设备、工程车辆、配件、化工、大宗农产品）。
用途：遇到陌生报价文件时先对号入座，选择解析策略。

## 五大格式类型

### 类型 1：万达自有报价模板（贸易商对外报价，出现频率最高）
- 特征：抬头 "WANDA INDUSTRIAL GROUP (WD) LIMITED / ROOM 509, NO.132 MENGDU AVENUE..."，
  xlsx+pdf 双份，FOB CHINA PORT，带图片列，同品类多版本（0815-4、0811-10 等版本号命名）
- 实例：东风喷油器、传送带、刹车油密封胶、火花塞、埃及制冰机、送料机
- 解析：标准表格直读。**这是平台的目标输出格式**——平台应能一键生成这个形态
- 坑：同品类多版本并存，必须按"日期+版本号"取最新，旧版标记归档

### 类型 2：厂家 brochure 型（工程机械主流）
- 特征：SHANTUI/XCMG/Sany/Maeda 等，技术参数册（ENGINE MODEL/Prime Power/性能曲线），
  一个型号一个 PDF，常无价格或只有系列价
- 实例：泰国项目 20+ 份（SD32/SE245/XLC200/AC 系列发电机组）、吊管机 90 吨曲线图
- 解析：抽"型号→关键参数"对，价格单独找 quotation sheet；brochure 本身不是报价单
- 坑：同一设备 brochure 和 quotation 分属两个文件，需要配对

### 类型 3：单机报价单（设备 1-3 台）
- 特征：QUOTATION SHEET + 图片 + Main Specifications + FOB 港价 + 交货期/质保期
- 实例：小米 YU7 MAX、吉利 RD6 皮卡、洗轮机、迷你履带吊、剪叉车
- 解析：单实体抽取（型号/参数/价格/交期/质保），注意"图片仅供参考"免责条款
- 优秀范本：脚手架报价（Q20240126）——**自带 HS CODE + SHIPPING DETAILS 列**，
  是 canonical 表 D 组的现实佐证

### 类型 4：大宗商品文书（LOI/FCO/Profile/Analysis Certificate）
- 特征：鸡爪、葵花籽油、HDPE——LOI 意向书、FCO 全责报盘、公司资质、化验单
- 解析：**超出 BOQ 管线范围**，识别后归类"贸易文书"另案处理，不要强行当报价解析
- 价值：是未来"合同审核模块"的训练样本（FCO 里的软条款、有效期、付款方式）

### 类型 5：图片型询价/报价
- 特征：WhatsApp 截图（陶瓷罐 15 张）、产品照片（三聚氰胺面板 13 张 jpg）
- 解析：需 OCR 或人工读图；当前管线标记"图片型"并提示用户，不硬猜
- 产品含义：真实世界里客户就是这样发需求的——图片识别是免费工具的杀手级入口

## 文件健康问题（实测）
- 老版格式：.xls ×7、.doc ×3（吊管机、地坪机、洗轮机说明书等）——需先转格式
- 损坏文件：~$ 临时文件、Bad CRC 的 docx（鸡爪规格书）、缺 word/NULL 的 docx（沙克曼）
- 压缩包未展开：新建文件夹 (3).7z / (4).7z
- 扫描 PDF：吊管机、摊铺机、TOWER CRANE 等提取为空——OCR 路线待建

## 解析策略速查
| 信号 | 策略 |
|---|---|
| WANDA 抬头 | 直读表格，注意版本号取最新 |
| ENGINE MODEL/性能曲线 | brochure 模式：抽型号参数对，价格另找 |
| QUOTATION SHEET+图片 | 单实体抽取 |
| LOI/FCO/LETTER OF INTENT | 贸易文书，转合同审核模块 |
| WhatsApp 截图/jpg | 标记图片型，提示 OCR/人工 |
| .xls/.doc | 先转 xlsx/docx 再解析 |
| 提取为空 | 扫描件，提示 OCR |

## v1.4 新增亚型（第一批采购/代表案例实证）

### 亚型 A：厂家报价软件生成件
- 特征：报价编号+软件版本号+数据库版本号三行签名（海信 V3.0.2），格式极规整，每机一册选型报告 sheet
- 策略：**快速通道**——列位固定，规则化直解

### 亚型 B：BOQ 填价回报件
- 特征：ITEM REF/描述与 BOQ 原文一一对应，厂家就地填 RATE（佛山照明=C6 BOQ 填价；沙特 RLB 厂家就地加列）
- 策略：与 BOQ 底稿按 REF 对位，直接进对账管线；注意 BOQ 各 section 编号循环重复（N 码多次出现）
- 变体：**机翻询价底稿**（"转入总汇总"/"米odule"）——RATE 列空，是询价件不是报价（规则 16）

### 亚型 C：设计台账+报价混合簿
- 特征：同一文件含设计选型台账（多方负荷计算演化痕迹，如 IES/Contract/JAIN/Stroi 四列）+ 按型号汇总报价 sheet；台账 sheet 超宽（VIC 列级）
- 策略：区分"设计区"与"报价区"，报价区进管线，设计区做参数溯源参考

### 亚型 D：方案型报价（纯文字需求→方案 PDF）
- 特征：客户只给描述性需求邮件，厂家回方案书（技术方案+设备清单+汇总价+企业简介+案例集），无 BOQ 行项
- 策略：第二管线——需求结构化→覆盖矩阵→跨文件核对（CHP 诉求 vs 凝汽式机组这类矛盾只有跨文件才浮现）
- 坑：暂定价占比（发电厂 43%）、双价格体系（÷1.2）、模板残留（FAMSUN）

### 亚型 E：纵向深度报价（电梯类）
- 特征：按梯号分组，每组参数五要素+选配清单+装饰材质代码；docx 跨页断表（27 个 TABLE 按 CRM Row No. 重组）；同 REF No. docx+PDF 双版
- 策略：梯号为锚，五要素归一化后再比价（规则 13）；l/1/I 混淆归一（规则 19）

### 亚型 F：价目表型（price list）
- 特征：厂家标准价目（名称/规格/单价/税率），不按 BOQ 行项填价（日丰 320 行）
- 策略：第三管线——BOQ 规格→价目检索取价+未匹配清单；不做行对行对账

### 亚型 G：用户中间表（万达"表格_YYYYMMDD"系列）
- 特征：在线协作文档导出的 xlsx，sheet 名"表格_20260610 (14)"式；列：系统分类|ITEM REF|完整描述|数量|材质/规格|含税单价/合价|美元单价/合价|认证备注；统一汇率（实测 7.10）；分已填价版与未填价底稿（*-BJ）
- 策略：**canonical 输出的现实锚点**，格式直接对齐；未填价版=询价底稿视图
- 坑：目录多副本（A11-BJ ×3），先聚类去重（规则 14）；价格可能含 AI 估算（需来源标签）
