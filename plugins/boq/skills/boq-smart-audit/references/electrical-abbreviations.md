# 电气 / 机电缩写词表（解析必备）

> 用途：解析 BOQ / 询价单 / 厂家报价单时，把英文缩写**按行业标准还原**，禁止音译、禁止改写成形近英文单词。
> 来源：2026-10-04 平台验收实测缺陷（LV Panels BOQ 中 MCB/MCCB 被解析为 "McCabe's" / "Mob's" / "Crib's"）+ 电气照明 C 包实战术语。

## 0. 铁律（三条）

1. **原文缩写必须在 `description` 原样保留**，不得替换、不得删除。
2. **`description_cn` 写中文全称**：`MCB 32A SPN` → `微型断路器 32A 单极+N`。
3. **不确定就原样保留缩写**，绝不猜测、绝不硬凑成一个真实存在的英文单词（这是 McCabe's 类事故的根源）。

## 9. 解析后自检清单

- [ ] 是否出现看似人名/品牌名的英文词（McCabe's、Crib）？→ 极可能是缩写被误读
- [ ] `description_cn` 是否有空值？→ 必须逐条非空
- [ ] 编号/位号（LV 1 - B 01 / R、C1-01、DB-1A）是否混进了 `description`？→ 只应进 `ref`
- [ ] 数量是否存在异常整百/异常大值（如 442）？→ 疑似章节行或楼层范围，标疑不照收
- [ ] 品类是否逐条判断（不应全部同一品类）？→ 混装单子必须逐条分类
