# 外贸订单智能分析比对（BOQ Smart Audit）

BOQ 询价单 / 厂家报价单智能解析、错漏校验、多厂比价技能。

## 能力

- **解析**：xlsx / xls / pdf / docx / zip 全格式 BOQ 与报价单提取（含隐藏 sheet、合并单元格、跨页断表）
- **校验**：22 条规则引擎——金额三算、参数漂移分级、同码不同物、隐含行项、凑套检查、暂定价置信度、双价格体系检测等
- **对账**：BOQ × 厂家报价 × 人工汇总三方归一化对位，错例带行号溯源
- **比价**：多厂同品报价参数五要素归一化后比价（先归一、再比价）
- **输出**：统一中间表格式（含税 CNY+USD 双列、HS 编码品类库、危品标记）

## 安装

```bash
# 添加市场
/plugin marketplace add <本仓库地址>

# 安装插件
/plugin install boq@boq-market
```

## 使用

上传 BOQ 或报价文件后直接提出需求，例如：

- "解析这份询价表并检查有没有错漏"
- "把这两家厂家报价做个比价"
- "厂家报价和 BOQ 对一下，看有没有参数漂移和漏项"

## 数据与隐私

原始文件仅本地解析，不上传外部服务。纠错数据（可选）匿名回流用于规则库改进。
