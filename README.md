# Wanda 外贸数字化技能市场

两个经过真实业务验收的技能插件：**BOQ 智能分析比对** 与 **SaaS 平台创立蓝图**。

## 插件一：BOQ Smart Audit（boq）

BOQ 询价单 / 厂家报价单智能解析、错漏校验、多厂比价技能。

- **解析**：xlsx / xls / pdf / docx / zip 全格式 BOQ 与报价单提取（含隐藏 sheet、合并单元格、跨页断表、扫描件视觉通道）
- **校验**：36 条规则引擎——金额三算、参数漂移分级、同码不同物、隐含行项、凑套检查、暂定价置信度、双价格体系检测等
- **对账**：BOQ × 厂家报价 × 人工汇总三方归一化对位，错例带行号溯源
- **比价**：多厂同品报价参数五要素归一化后比价（先归一、再比价）
- **输出**：统一中间表格式（含税 CNY+USD 双列、HS 编码品类库、危品标记）
- **工程坑位**：平台级解析管线 9 条实战坑位（宽表截断、表头错位、预过滤、模型选型、围栏容错、视觉通道、存量修复管线）

## 插件二：SaaS Platform Blueprint（saas-blueprint）

从 0 到 1 创立并跑通一个行业 SaaS 平台的蓝图与关键代码骨架。

- **五阶段路线**：需求建模 → 单文件架构 → 数据模型与 RLS → 角色与审批流 → 发布与验收
- **关键代码骨架**：四表单登录、角色 gate、审计留痕、AI 解析链路、批量数据资产化管线、Node 服务端垫片
- **设计决策表**：9 项关键决策（单文件分区纪律、boot 顺序、i18n 陷阱、迁移纪律、42501/401 排错）
- **附录**：外贸报价平台专用手册（7+1 表实例、三角色套路、已验收清单）

## 安装

```bash
# 添加市场
/plugin marketplace add <本仓库地址>

# 安装插件
/plugin install boq@boq-market
/plugin install saas-blueprint@boq-market
```

## 使用

- **BOQ**：上传询价表或报价文件后直接提出需求，例如"解析这份询价表并检查有没有错漏"、"把这两家厂家报价做个比价"
- **蓝图**：提出平台搭建需求，例如"帮我做一个带供应商门户的报价平台"、"把这个脚本工具升级成多角色在线系统"

## 数据与隐私

原始文件仅本地解析，不上传外部服务。纠错数据（可选）匿名回流用于规则库改进。
